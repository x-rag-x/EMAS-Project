Deletes all browser storage and cached data. Also runs automatically on logout.

Select and permanently delete Departments, Students, Teachers, Classes, or Subjects from the database.

Delete attendance records by date range, or wipe all records at once.
🧹 Clear Activity Logs
Permanently deletes all system activity and login logs. Admin only.
💥 Clear Entire Database
Wipes ALL collections: students, teachers, departments, classes, subjects, attendance, timetables, notifications, logs. Admin account is preserved.
⚠️ All destructive actions require admin password confirmation. These operations call the server API and immediately affect the MongoDB database. Deleted items can be undone within 10 days via the Undo menu.
